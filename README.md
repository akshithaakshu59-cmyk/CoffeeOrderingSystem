# ☕ Coffee Ordering System

## Overview
The Coffee Ordering System is a simple Java console-based application that allows users to order coffee, customize their order with add-ons, and calculate the final bill. This project demonstrates the use of Java programming concepts such as conditional statements, switch cases, user input handling, and basic billing logic.

## Features
- Select from multiple coffee options:
  - Espresso
  - Cappuccino
  - Latte
- Add whipped cream as an extra topping.
- Choose a flavour shot:
  - Vanilla
  - Hazelnut
- Automatic bill calculation.
- User-friendly console interface with Unicode symbols.

## Technologies Used
- Java
- IntelliJ IDEA (or any Java IDE)
- Scanner Class

## Concepts Used
- Variables and Data Types
- Conditional Statements (if-else)
- Switch Case
- User Input using Scanner
- Basic Arithmetic Operations

## How to Run
1. Clone the repository.
2. Open the project in IntelliJ IDEA or any Java IDE.
3. Compile and run `CoffeeOrderingSystem.java`.
4. Follow the on-screen instructions to place your order.
